# Environment Reproducibility

Conserva qui lockfile, note CUDA/driver, container recipe o environment YAML.

Per ogni esperimento importante registra il riferimento all'ambiente in `experiment.yaml`.

Esempi:
- `uv.lock`
- `requirements-lock.txt`
- `conda-lock.yml`
- `Dockerfile`
- `environment.yml`

Non affidarti alla frase "usa l'ambiente attuale".
