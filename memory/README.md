# ARCA Memory layer

CortexDB è un **adattatore facoltativo**. Nessun file della repo richiede CortexDB per essere letto, compilato o validato.

- `CORTEXDB.md`: installazione e troubleshooting.
- `MEMORY_POLICY.md`: cosa ricordare, cosa no, provenance e privacy.
- `SCHEMA.md`: relazioni semantiche raccomandate (schema concettuale, non migrazione DB).

La memoria derivata è un indice recuperabile, non fonte primaria dei risultati scientifici.
