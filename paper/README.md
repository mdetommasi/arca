# Paper Workspace

Il manoscritto è una vista derivata della conoscenza del progetto, non la sua unica memoria.

Flusso consigliato:

`experiments + literature -> findings -> paper/CLAIMS.md -> manuscript`

Prima di cambiare un numero, una conclusione o una frase forte nel manoscritto:
1. aggiorna/verifica il claim corrispondente;
2. verifica gli experiment/source ID;
3. verifica che non esista una contraddizione aperta;
4. aggiorna figure/tabelle;
5. solo allora modifica il testo.
