# Reports

Conserva qui report tecnici, milestone report, internal review e snapshot destinati a persone.

I report NON devono diventare una seconda fonte di verità scollegata:
- risultati scientifici -> `research/FINDINGS.md`;
- provenance -> `experiments/` e `artifacts/`;
- claim pubblicabili -> `paper/CLAIMS.md`;
- report -> sintesi derivata da queste fonti.
