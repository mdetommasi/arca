# Research Decision Records (RDR)

Crea un RDR quando una scelta influenza il futuro del progetto e non è ovvia dal codice.

Esempi:
- cambio protocollo di validazione;
- esclusione di una feature;
- scelta di una baseline;
- cambio metrica;
- cambio dataset;
- accettazione/rifiuto di una spiegazione;
- scelta di non perseguire una linea di ricerca.

Copia `RDR-000-template.md` in un nuovo file numerato.
