# Literature Workspace

Obiettivo: trasformare la review bibliografica da elenco di paper a base di evidenza interrogabile.

Per ogni fonte importante crea una nota `papers/P-####-short-title.md`.

Registra almeno:
- domanda a cui la fonte contribuisce;
- claim principali;
- metodo/dataset;
- evidenza utile;
- limiti;
- conflitti con altre fonti;
- riproducibilità;
- relazione con il tuo lavoro.

Aggiorna `EVIDENCE_MATRIX.md` per confrontare le fonti per claim/domanda.
Mantieni `library.bib` come bibliografia canonica.
